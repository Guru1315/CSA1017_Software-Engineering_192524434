# CSA1017: Software Engineering

Coursework for **CSA1017, Software Engineering** at SIMATS Engineering (Saveetha School of Engineering), Department of Computer Science and Engineering.

## What is in this repository

| Folder | Contents | Status |

| `CAPSTONE PROJECTS` (other folders) | Capstone presentation, report, one-page write-up and geo tags | Not added yet |

## Topics covered

- **Agile project management:** Scrum, sprint planning, user stories, backlog prioritisation and definition of done
- **Case study analysis:** requirements, stakeholders, methodology comparison and risk analysis for a predictive maintenance platform
- **Workflow tools:** Kanban boards in Jira and Trello
- **Design:** a clickable app prototype in Figma
- **Capstone:** an AI software-team console built with n8n and Supabase
