# Lab experiments

Three software engineering tool exercises. Each folder holds one screenshot of the work and a README that describes it.

| Experiment | Tool | What the screenshot shows |
|---|---|---|
| [EXP 1](EXP%201/README.md) | Jira | A Kanban board with five tasks across To Do, In Progress and Done |
| [EXP 2](EXP%202/README.md) | Figma | A five-screen bus ticket booking prototype |
| [EXP 3](EXP%203/README.md) | Trello | A Kanban workflow board with the same five tasks |

EXP 1 and EXP 3 use the same five tasks in two different tools, which makes the two boards easy to compare.
