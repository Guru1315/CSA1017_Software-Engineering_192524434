## What it shows

A Kanban board with three columns and five work items:

| Column | Items |
|---|---|
| To Do (2) | KWP-4 Test application, KWP-5 Prepare final report |
| In Progress (2) | KWP-1 Collect project requirements, KWP-3 Develop login module |
| Done (1) | KWP-2 Design UI mockups |
